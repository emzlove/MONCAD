MONCAD Learning Academy

Practical learning resources for design and creative workflows.

LEARN • PRACTISE • CREATE
Learning resource notice

MONCAD Academy provides tutorials and practical learning activities. It is not presented as an accredited educational institution and does not award academic qualifications or formal certificates.

LESSON 01

Introduction to Architecture Design

Understand the basics of floor plans, room layouts and architectural drawing.

  1. Identify the purpose of a floor plan.
  2. Learn how walls, doors and windows are represented.
  3. Practise drawing a simple room layout.
  4. Check dimensions and proportions before saving.
LESSON 02

Understanding Measurements

Learn how dimensions and measurement units support accurate design work.

  1. Understand metres, centimetres and millimetres.
  2. Learn why consistent units matter.
  3. Practise measuring a room.
  4. Record dimensions clearly on a drawing.
LESSON 03

Fashion Sketching Basics

Explore sketching tools, garment concepts and creative design development.

  1. Start with a simple garment silhouette.
  2. Use lines to define shape and construction.
  3. Experiment with colour and details.
  4. Save versions as your design develops.
LESSON 04

Saving and Organising Projects

Learn to name, save and preserve design project versions.

  1. Give each project a clear name.
  2. Save a new version after important changes.
  3. Keep exported copies in a safe location.
  4. Record the date and design category.
