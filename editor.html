LEARN • PRACTISE • CREATE
Learning and practical guidance

MONCAD Learning Academy provides educational tutorials and platform guidance. It does not currently provide accredited academic programmes, government-recognised qualifications or formal training certificates.

LESSON 01

Introduction to Architecture

Discover the basic principles of architectural planning and design.

  1. Understand the purpose of a floor plan.
  2. Identify rooms, walls, doors and windows.
  3. Learn why accurate measurements matter.
  4. Explore the difference between 2D and 3D design.
LESSON 02

Floor Plan Fundamentals

Learn how rooms, circulation and measurements work together.

  1. Start with the overall building dimensions.
  2. Plan room locations and circulation paths.
  3. Consider door and window placement.
  4. Review dimensions before finalising a concept.
LESSON 03

Introduction to Fashion Design

Explore garment concepts, silhouettes, colours and design sketches.

  1. Choose a garment category and design purpose.
  2. Explore silhouettes and proportions.
  3. Develop a sketch using drawing tools.
  4. Save and review earlier design drafts.
LESSON 04

Using MONCAD

Get familiar with the studios, drawing tools and project workflow.

  1. Choose the studio you want to use.
  2. Explore the available tools and settings.
  3. Create a practice project.
  4. Save your work and export available records.
