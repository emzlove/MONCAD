
# MONCAD

### Advanced 2D & 3D Architectural Design Platform

MONCAD is a web and mobile architectural design platform that empowers students, architects, designers, engineers, and construction companies to create professional floor plans and 3D building models without coding.

## Main Features

- Interactive 2D Floor Planning
- Advanced 3D Architectural Modeling
- Drag-and-Drop Furniture Library
- Building Materials and Textures
- Automatic 2D-to-3D Synchronization
- Design Templates
- Figma and Canva Integration
- Project Management
- Team Collaboration
